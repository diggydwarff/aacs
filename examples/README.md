# Example zones

`zones.json` is illustrative, not live policy and not automatically imported. Change coordinates to fit your test area, then enter each zone through HQ's menu. The secure-facility example overlaps the airbase: a craft in both needs a permit for both. All examples apply to ships, not pedestrians.

Do not copy any secret, state file or live credential into this examples directory. `aacs/tests` contains deliberately public fixed test fixtures only.
